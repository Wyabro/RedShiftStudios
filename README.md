# RedShift Portfolio (Single-Page)

Single-page HTML/CSS/JS portfolio site for a cinematic video production business.

## Run locally

- Open `index.html` directly in your browser, or
- Use a simple local server (recommended for embeds/forms):

```powershell
cd C:\Users\wyatt\redshift-portfolio
python -m http.server 5173
```

Then visit `http://localhost:5173`.

## Formspree setup

In `index.html`, replace:

- `https://formspree.io/f/YOUR_FORM_ID`

with your real Formspree form endpoint.

## Netlify deploy

- Drag-and-drop the folder in Netlify, or connect the repo.
- No build step needed (static site).
